# Standard Library Stability Levels

本页定义 Zun 标准库模块的稳定级别。

## 级别定义

### `experimental`

默认级别。

特点：

- 可以快速演进
- 兼容承诺最弱
- 允许在文档和测试补齐前继续探索

要求：

- 有模块 README
- 有最小示例
- 有最小测试

### `preview`

用于已经具备清晰方向、但还不想承诺长期冻结 API 的模块。

特点：

- 允许继续迭代
- 需要开始提供更明确的兼容说明
- 适合收集社区反馈

升级前至少要具备：

- 文档完整
- 示例完整
- 测试齐全
- 兼容策略已说明

### `stable`

用于已经进入长期兼容承诺的标准库模块。

特点：

- 公共 API 不得随意重写
- 任何 breaking change 都必须走 RFC 或兼容说明
- 弃用与移除必须遵循 `docs/spec/deprecation.md`

升级前至少要具备：

- 文档、示例、测试齐全
- 经过一段时间的稳定使用
- 兼容策略明确
- 评审结论同意进入长期承诺范围

## 升级规则

- 新模块默认 `experimental`
- 文档、测试、兼容策略齐全后可升 `preview`
- 经过稳定使用和兼容承诺后可升 `stable`

## 当前默认状态

Phase 10 完成时，仓库中的现有 stdlib 目录默认都视为 `experimental`，直到各自具备完整 README、示例、测试与兼容说明。
