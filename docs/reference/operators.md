# 运算符

Zun 支持丰富的运算符，可以用于构建表达式。

## 算术运算

```zun
$>> 1 + 2;
3

$>> 10 - 3;
7

$>> 4 * 5;
20

$>> 10 / 3;
3.3333333333333335

$>> 10 % 3;
1

$>> "Hello" + " " + "World";
Hello World
```

| 运算符 | 说明 | 示例 |
|--------|------|------|
| `+` | 加法 / 字符串连接 | `1 + 2` → `3` |
| `-` | 减法 | `5 - 3` → `2` |
| `*` | 乘法 | `4 * 3` → `12` |
| `/` | 除法（浮点） | `10 / 3` → `3.33...` |
| `%` | 取模 | `10 % 3` → `1` |

### 复合赋值运算

| 运算符 | 说明 | 示例 |
|--------|------|------|
| `+=` | 加法赋值 | `a += 1` 等价于 `a = a + 1` |
| `-=` | 减法赋值 | `a -= 1` 等价于 `a = a - 1` |
| `*=` | 乘法赋值 | `a *= 2` 等价于 `a = a * 2` |
| `/=` | 除法赋值 | `a /= 2` 等价于 `a = a / 2` |
| `%=` | 取模赋值 | `a %= 3` 等价于 `a = a % 3` |

## 比较运算

```zun
$>> 5 == 5;
true

$>> 5 != 3;
true

$>> 10 > 5;
true

$>> 3 < 7;
true

$>> 5 >= 5;
true

$>> 3 <= 4;
true
```

| 运算符 | 说明 | 示例 |
|--------|------|------|
| `==` | 相等 | `5 == 5` → `true` |
| `!=` | 不等 | `5 != 3` → `true` |
| `>` | 大于 | `10 > 5` → `true` |
| `<` | 小于 | `3 < 7` → `true` |
| `>=` | 大于等于 | `5 >= 5` → `true` |
| `<=` | 小于等于 | `3 <= 4` → `true` |

---

## 逻辑运算

```zun
$>> true && true;
true

$>> true && false;
false

$>> true || false;
true

$>> false || false;
false

$>> !false;
true

$>> !true;
false
```

| 运算符 | 说明 | 示例 |
|--------|------|------|
| `&&` | 逻辑与 | `true && false` → `false` |
| `\|\|` | 逻辑或 | `false \|\| true` → `true` |
| `!` | 逻辑非 | `!true` → `false` |

---

## 运算符优先级

运算符按照以下优先级从高到低执行：

| 优先级 | 运算符 | 说明 |
|--------|--------|------|
| 1 | `!` | 逻辑非 |
| 2 | `*`, `/`, `%` | 乘除取模 |
| 3 | `+`, `-` | 加减 |
| 4 | `==`, `!=`, `>`, `<`, `>=`, `<=` | 比较运算 |
| 5 | `&&` | 逻辑与 |
| 6 | `\|\|` | 逻辑或 |

可以使用括号改变优先级：

```zun
$>> 1 + 2 * 3;      // 7 (先算乘法)
$>> (1 + 2) * 3;   // 9 (先算加法)
```
