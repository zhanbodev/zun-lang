# HTTP-001 `@SET_HDR` Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `@SET_HDR({ "Header-Name": "value", ... })` so Zun HTTP routes and HTTP blocks can emit fixed response headers with route-level override.

**Architecture:** Add `@`/`@SET_HDR` support in the frontend, carry parsed headers through `HttpRoute` metadata in the runtime, merge block and route headers during route registration, and append the final headers when Axum builds the HTTP response. Fail fast on invalid placement, invalid syntax, same-node duplicate header names, and invalid runtime header conversion.

**Tech Stack:** Rust, Zun frontend parser/AST, Zun runtime, Axum, tower-http-free Axum response building, Rust integration tests

// parser/stmt/http.rs
fn parse_set_hdr_annotations(&mut self) -> Result<Vec<SetHdrEntry>, Error> {
    let mut headers = Vec::new();
    let mut seen = std::collections::HashSet::new();

    while !self.at_end() && self.peek().typ == Type::AtSetHdr {
        self.advance();
        self.expect(Type::LParen)?;
        let name = self.expect_string_literal_for_set_hdr()?;
        self.expect(Type::Comma)?;
        let value = self.expect_string_literal_for_set_hdr()?;
        self.expect(Type::RParen)?;

        let normalized = name.to_ascii_lowercase();
        if !seen.insert(normalized) {
            return Err(self.set_hdr_syntax_error("duplicate @SET_HDR header name on the same node"));
        }

        headers.push(SetHdrEntry { name, value });
    }

    Ok(headers)
}
```

// interpreter/exec/http.rs
fn merge_response_headers(
    block_headers: &[crate::ast::SetHdrEntry],
    route_headers: &[crate::ast::SetHdrEntry],
) -> Vec<(String, String)> {
    let mut merged: Vec<(String, String)> = block_headers
        .iter()
        .map(|entry| (entry.name.clone(), entry.value.clone()))
        .collect();

    for entry in route_headers {
        let normalized = entry.name.to_ascii_lowercase();
        if let Some(existing) = merged
            .iter_mut()
            .find(|(name, _)| name.to_ascii_lowercase() == normalized)
        {
            existing.1 = entry.value.clone();
        } else {
            merged.push((entry.name.clone(), entry.value.clone()));
        }
    }

    merged
}
```

```rust
fn build_http_response(
    result: Option<ZunValue>,
    return_type: &str,
    response_headers: &[(String, String)],
) -> axum::response::Response {
    let mut response = build_body_response(result, return_type);

    for (name, value) in response_headers {
        let header_name = axum::http::header::HeaderName::try_from(name.as_str())
            .unwrap_or_else(|_| panic!("ZUN-C003: invalid response header name: {name}"));
        let header_value = axum::http::HeaderValue::try_from(value.as_str())
            .unwrap_or_else(|_| panic!("ZUN-C003: invalid response header value for {name}"));
        response.headers_mut().insert(header_name, header_value);
    }

    response
}
```
